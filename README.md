# ผู้ช่วยครู (Teacher Assistant)

เว็บแอปสำหรับช่วยครูจัดการงานสอนประจำวัน สร้างด้วย React + TypeScript + Vite + Tailwind CSS
ข้อมูลทั้งหมดเก็บไว้ใน `localStorage` ของเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูลภายนอก

## ฟีเจอร์หลัก

- **ภาพรวม (Dashboard)** — สรุปจำนวนนักเรียน อัตราการเข้าเรียน คะแนนเฉลี่ย งานที่ใกล้ครบกำหนด และแผนการสอนล่าสุด
- **นักเรียน** — จัดการห้องเรียน/วิชา และรายชื่อนักเรียนในแต่ละห้อง
- **เช็คชื่อ** — บันทึกสถานะเข้าเรียนรายวัน (มา/ขาด/ลา/สาย) พร้อมสรุปยอด
- **คะแนน** — สร้างรายการคะแนน (สอบ/เก็บคะแนน) และบันทึกคะแนนรายบุคคล พร้อมคำนวณคะแนนรวม
- **งาน/การบ้าน** — มอบหมายงานพร้อมกำหนดส่ง และติดตามสถานะการส่งงานของนักเรียนแต่ละคน
- **แผนการสอน** — บันทึกแผนการสอนรายคาบ (หัวข้อ, จุดประสงค์, กิจกรรม, สื่อการสอน)
- **คำศัพท์ & แบบทดสอบ** — คลังคำศัพท์ภาษาอังกฤษ พร้อมระบบสุ่มทำแบบทดสอบแบบเลือกตอบ (เหมาะสำหรับครูสอนภาษาอังกฤษ)
- **พากย์เสียง (Text-to-Speech)** — แปลงข้อความเป็นเสียงด้วย Web Speech API ของเบราว์เซอร์ (ฟรี ไม่ต้องใช้ API key)
  - เลือกเสียงผู้พากย์ได้ทุกเสียงที่มีในเครื่อง หรือโหมดอัตโนมัติที่อ่านภาษาไทยด้วยเสียงไทยและภาษาอังกฤษด้วยเสียงอังกฤษ
  - รูปแบบเสียงสำเร็จรูป 12 แบบ: ปกติ, ผู้บรรยาย, ผู้ประกาศข่าว, เด็ก, คนชรา, ยักษ์, ตัวการ์ตูน, หุ่นยนต์, ตื่นเต้น, กระซิบ, ช้า (ฝึกฟัง), เร็ว พร้อมปรับความเร็ว/ระดับเสียง/ความดังเองได้
  - โหมด **บทพากย์หลายตัวละคร** — เขียนบทแบบ `ชื่อ: ข้อความ` กำหนดเสียงให้แต่ละตัวละคร ใส่ช่วงเงียบด้วย `[หยุด 2]` และคลิกเล่นจากบรรทัดใดก็ได้
  - มี 2 เครื่องยนต์เสียง:
    - **เสียงเบราว์เซอร์** — ฟรี ไม่ต้องตั้งค่า แต่ฟังได้อย่างเดียว (แนะนำ Microsoft Edge เพื่อเสียงไทยคุณภาพสูง)
    - **Google Cloud Text-to-Speech** — เสียงสมจริง **ดาวน์โหลดเป็นไฟล์ .wav** ไปใส่วิดีโอได้ (CapCut, Canva, Clipchamp ฯลฯ)
      ทั้งไฟล์รวมทั้งบท และไฟล์แยกทีละบรรทัด ต้องใช้ API key ของ Google Cloud (มีโควตาฟรีรายเดือน — ขั้นตอนขอ key อยู่ในหน้าโปรแกรม)

### ตั้งค่า Google API key ล่วงหน้า (สำหรับห้องคอมพิวเตอร์)

ปกติครูต้องวาง API key ในหน้าโปรแกรมครั้งแรกบนแต่ละเครื่อง (key จะเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น)
หากต้องการให้ทุกเครื่องใช้ได้ทันที ให้สร้างไฟล์ `.env.local` ก่อน build:

```bash
VITE_GOOGLE_TTS_KEY=AIza...
```

> ⚠️ key ที่ฝังไว้แบบนี้จะอยู่ในไฟล์ JavaScript ของเว็บ ใครเปิดเว็บก็ดูได้ จึง**ต้อง**จำกัด key ให้ใช้ได้เฉพาะ
> Cloud Text-to-Speech API และเฉพาะเว็บไซต์ของโปรแกรม (Website restrictions) และตั้ง Budget alert ไว้เสมอ

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ URL ที่ Vite แสดง (ปกติคือ `http://localhost:5173`)

## คำสั่งอื่น ๆ

```bash
npm run build    # build สำหรับ production
npm run preview  # preview production build
npm run lint     # ตรวจสอบโค้ดด้วย oxlint
```
