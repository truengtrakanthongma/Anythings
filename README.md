# ผู้ช่วยครู (Teacher Assistant)

เว็บแอปสำหรับช่วยครูจัดการงานสอนประจำวัน สร้างด้วย React + TypeScript + Vite + Tailwind CSS
ข้อมูลทั้งหมดเก็บไว้ใน `localStorage` ของเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูลภายนอก

## ฟีเจอร์หลัก

- **ภาพรวม (Dashboard)** — สรุปจำนวนนักเรียน อัตราการเข้าเรียน คะแนนเฉลี่ย งานที่ใกล้ครบกำหนด และแผนการสอนล่าสุด
- **นักเรียน** — จัดการห้องเรียน/วิชา และรายชื่อนักเรียนในแต่ละห้อง
- **เช็คชื่อ** — บันทึกสถานะเข้าเรียนรายวัน (มา/ขาด/ลา/สาย) พร้อมสรุปยอด
- **คะแนน** — สร้างรายการคะแนน (สอบ/เก็บคะแนน) และบันทึกคะแนนรายบุคคล พร้อมคำนวณคะแนนรวม
- **งาน/การบ้าน** — มอบหมายงานพร้อมกำหนดส่ง และติดตามสถานะการส่งงานของนักเรียนแต่ละคน
- **แผนการสอน** — บันทึกแผนการสอนรายคาบ (หัวข้อ, จุดประสงค์, กิจกรรม, สื่อการสอน)
- **คำศัพท์ & แบบทดสอบ** — คลังคำศัพท์ภาษาอังกฤษ พร้อมระบบสุ่มทำแบบทดสอบแบบเลือกตอบ (เหมาะสำหรับครูสอนภาษาอังกฤษ)
- **พากย์เสียง (Text-to-Speech)** — แปลงข้อความเป็นเสียงด้วย Web Speech API ของเบราว์เซอร์ (ฟรี ไม่ต้องใช้ API key)
  - เลือกเสียงผู้พากย์ได้ทุกเสียงที่มีในเครื่อง หรือโหมดอัตโนมัติที่อ่านภาษาไทยด้วยเสียงไทยและภาษาอังกฤษด้วยเสียงอังกฤษ
  - รูปแบบเสียงสำเร็จรูป 12 แบบ: ปกติ, ผู้บรรยาย, ผู้ประกาศข่าว, เด็ก, คนชรา, ยักษ์, ตัวการ์ตูน, หุ่นยนต์, ตื่นเต้น, กระซิบ, ช้า (ฝึกฟัง), เร็ว พร้อมปรับความเร็ว/ระดับเสียง/ความดังเองได้
  - โหมด **บทพากย์หลายตัวละคร** — เขียนบทแบบ `ชื่อ: ข้อความ` กำหนดเสียงให้แต่ละตัวละคร ใส่ช่วงเงียบด้วย `[หยุด 2]` และคลิกเล่นจากบรรทัดใดก็ได้
  - มี 2 เครื่องยนต์เสียง:
    - **✨ เสียง AI (Gemini / Google AI Studio)** — เสียงเหมือนคนจริง กำหนดอารมณ์ได้ (เช่น "พูดเหมือนครูใจดี")
      อ่านไทยปนอังกฤษได้เป็นธรรมชาติ ดาวน์โหลดไฟล์ .wav ได้ทันที ทั้งไฟล์รวมและแยกทีละบรรทัด
      ใช้ API key **ฟรี** จาก [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (ไม่ต้องใช้บัตรเครดิต แต่มีโควตาจำกัดต่อนาที/ต่อวัน)
    - **🔈 เสียงเบราว์เซอร์** — ฟรีไม่จำกัด ใช้เมื่อโควตา AI หมด (แนะนำ Microsoft Edge เพราะมีเสียงไทย Natural) บันทึกเป็นไฟล์ผ่านการแชร์หน้าจอ

### วิธีใช้เสียง AI

1. ขอ API key ฟรีที่ [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key**
2. ในแท็บ "พากย์เสียง" เลือก **✨ เสียง AI (Gemini)** แล้ววาง key (key เก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น)
3. เลือกเสียง/รูปแบบเสียง แล้วกด **✨ สร้างเสียง AI** → **⬇ ดาวน์โหลด (.wav)**

> ข้อความที่สร้างแล้วจะไม่ถูกส่งซ้ำ เพื่อประหยัดโควตา · แบบฟรี Google อาจนำข้อความไปปรับปรุงบริการ จึงไม่ควรใส่ข้อมูลส่วนตัวของนักเรียน

### วิธีบันทึกเสียงเบราว์เซอร์เป็นไฟล์

เบราว์เซอร์ไม่มีช่องทางดึงเสียงพูดออกมาเป็นไฟล์โดยตรง โปรแกรมจึงอัดเสียงที่เครื่องพูดออกมา ผ่านการแชร์หน้าจอพร้อมเสียงของระบบ
(ใช้ได้กับ Chrome / Edge บน Windows และ ChromeOS — บน Mac และมือถือยังไม่รองรับการอัดเสียงระบบ)

1. กด **⏺ บันทึกเป็นไฟล์เสียง**
2. ในหน้าต่างที่เด้งขึ้น เลือก **ทั้งหน้าจอ (Entire screen)**
3. ติ๊ก **แชร์เสียงของระบบด้วย (Also share system audio)** แล้วกด **แชร์**
4. โปรแกรมจะอ่านบทและบันทึกเอง เมื่อจบจะได้ไฟล์ .wav ให้ดาวน์โหลด (ตัดช่วงเงียบหัว-ท้ายให้อัตโนมัติ)

> ระหว่างบันทึก ควรปิดเพลง/วิดีโออื่นและเสียงแจ้งเตือน เพราะเสียงทั้งหมดในเครื่องจะถูกอัดด้วย

## เริ่มต้นใช้งาน (สำหรับพัฒนาบนเครื่องตัวเอง)

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ URL ที่ Vite แสดง (ปกติคือ `http://localhost:5173`)

## คำสั่งอื่น ๆ

```bash
npm run build    # build สำหรับ production
npm run preview  # preview production build
npm run lint     # ตรวจสอบโค้ดด้วย oxlint
```
