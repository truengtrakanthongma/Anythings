# ผู้ช่วยครู (Teacher Assistant)

เว็บแอปสำหรับช่วยครูจัดการงานสอนประจำวัน สร้างด้วย React + TypeScript + Vite + Tailwind CSS
ข้อมูลทั้งหมดเก็บไว้ใน `localStorage` ของเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูลภายนอก

## ฟีเจอร์หลัก

- **ภาพรวม (Dashboard)** — สรุปจำนวนนักเรียน อัตราการเข้าเรียน คะแนนเฉลี่ย งานที่ใกล้ครบกำหนด และแผนการสอนล่าสุด
- **นักเรียน** — จัดการห้องเรียน/วิชา และรายชื่อนักเรียนในแต่ละห้อง
- **เช็คชื่อ** — บันทึกสถานะเข้าเรียนรายวัน (มา/ขาด/ลา/สาย) พร้อมสรุปยอด
- **คะแนน** — สร้างรายการคะแนน (สอบ/เก็บคะแนน) และบันทึกคะแนนรายบุคคล พร้อมคำนวณคะแนนรวม
- **งาน/การบ้าน** — มอบหมายงานพร้อมกำหนดส่ง และติดตามสถานะการส่งงานของนักเรียนแต่ละคน
- **แผนการสอน** — บันทึกแผนการสอนรายคาบ (หัวข้อ, จุดประสงค์, กิจกรรม, สื่อการสอน)
- **คำศัพท์ & แบบทดสอบ** — คลังคำศัพท์ภาษาอังกฤษ พร้อมระบบสุ่มทำแบบทดสอบแบบเลือกตอบ (เหมาะสำหรับครูสอนภาษาอังกฤษ)

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ URL ที่ Vite แสดง (ปกติคือ `http://localhost:5173`)

## คำสั่งอื่น ๆ

```bash
npm run build    # build สำหรับ production
npm run preview  # preview production build
npm run lint     # ตรวจสอบโค้ดด้วย oxlint
```
